# Python Quiz Application

## Description

Python Quiz Application is a GUI-based quiz platform developed using Tkinter. It presents multiple-choice questions to users, evaluates answers, calculates scores automatically, and displays the final result at the end of the quiz. The project provides a simple and interactive way to test knowledge while demonstrating Python GUI development concepts.

## Features

* Graphical User Interface (GUI) using Tkinter
* Multiple-choice questions
* Automatic answer evaluation
* Real-time score calculation
* Final result display
* User-friendly interface
* Interactive quiz experience

## Technologies Used

* Python 3
* Tkinter
* MessageBox Module

## Objectives

## Working of the Application

1. The application loads quiz questions from a predefined list.
2. Questions and options are displayed using Tkinter widgets.
3. Users select an answer using radio buttons.
4. Clicking the "Next" button checks the answer.
5. The score is updated automatically.
6. After the final question, the result is displayed in a popup message box.
